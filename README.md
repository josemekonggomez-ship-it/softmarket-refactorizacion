# SoftMarket - Refactorización y buenas prácticas

Repositorio simulado de la propuesta de buenas prácticas para SoftMarket S.A.
Autores: Jose Mekong y Luis Sierra.

## Ramas
- `main`: producción (protegida, solo versiones etiquetadas)
- `develop`: integración
- `feature/*`, `bugfix/*`, `release/*`, `hotfix/*`: ramas de trabajo

Consulta `CONTRIBUTING.md` para el flujo completo.
